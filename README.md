# 司机发货登记表生成器

从企业微信司机群原始消息解析为规范化11列表格，对标 MiniMax Code 输出质量。

## 快速开始

1. 下载 [司机发货登记.exe](https://github.com/wymanchui/driver-dispatch-exporter/releases)
2. 双击运行
3. 粘贴企业微信司机群消息
4. 点击「开始解析」
5. 保存 TXT + XLSX

## 输出格式（11列）

```
年月 | 日期 | 姓名 | 类型 | 客户 | 数量 | 拼车 | 车号 | 流水号 | 跟车 | 原始数据
```

详细规则说明见 [解析规则说明.md](解析规则说明.md)
